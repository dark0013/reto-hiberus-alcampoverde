# 🏥 Sistema de Gestión de Citas Médicas

## Descripción
Este proyecto es una **aplicación web full-stack** diseñada para la administración de citas médicas, pacientes y especialidades.  
La aplicación cuenta con un **frontend interactivo** construido con **HTML, Bootstrap 5 y JavaScript**, y un **backend robusto** que expone una **API RESTful**, desarrollada en **PHP**, para gestionar los datos en una base de datos **MySQL**.
